修改后的不变量定义
==================

记号与参数
----------

    end   >= 0
    vmax  >= 0
    amin  < 0
    amax  >= 0
    d     > 0（每次推导时给定的具体正有理数批注）
    sb    = vmax^2 / (-2*amin)

当前位置、速度和加速度分别记为 p、v、a。
end、vmax、amin、amax 保存在独立于状态 Gamma 的共享参数环境中；
类型推导对所有满足上述约束的参数预赋值成立。

经过一个控制周期 d 后的预测状态为：

    p_d = p + v*d + a*d^2/2
    v_d = v + a*d


一、位置不变量 phi_p
--------------------

定义：

    phi_p(p) := p <= end

定义动机：

phi_p 直接描述案例最基本的位置安全要求：车辆不能越过目标位置 end。
该性质本身没有造成原反例，因此保持原定义不变。


二、速度不变量 phi_v
--------------------

定义：

    phi_v(p,v) :=

        (p >= end and v <= 0)

        or

        (end-p >= sb and v <= vmax)

        or

        (0 < end-p < sb
         and
         (v <= 0 or v^2 <= (-2*amin)*(end-p)))

定义动机：

phi_v 根据车辆与终点的距离规定允许的速度范围。

1. 当车辆已经到达终点时，速度必须非正，不能继续向前运动。
2. 当车辆离终点较远时，只要求速度不超过 vmax。
3. 当车辆接近终点时，若仍向前运动，则当前速度必须满足最大制动能力 amin
   对应的制动距离约束：

       v^2 <= (-2*amin)*(end-p)

该条件保证在立即使用最大制动 a=amin 时，车辆能够在终点之前停下。
原反例并不是由 phi_v 的定义错误造成的，因此这里仍保留原三段式定义。


三、加速度不变量 phi_a
----------------------

先定义一个控制周期后的预测状态：

    p_d = p + v*d + a*d^2/2
    v_d = v + a*d

修改后的定义为：

    phi_a(p,v,a) :=

        amin <= a <= amax

        and phi_p(p_d)

        and phi_v(p_d,v_d)

        and

        (a >= 0
         or v <= 0
         or v_d > 0
         or v^2 <= -2*a*(end-p))

定义动机：

原来的 phi_a 只检查 d 时刻的预测状态是否满足 phi_v。这个条件不能保证
0 到 d 之间的整个连续轨迹安全：当 a<0、v>0 且 v_d<=0 时，车辆会先继续
向前运动，在速度降到 0 后再向后运动。此时 d 时刻可能重新安全，但中途的
最远位置可能已经越过 end。

修改后的 phi_a 增加了两类检查。

第一，周期终点必须同时满足位置安全和速度安全：

    phi_p(p_d) and phi_v(p_d,v_d)

这避免只检查 phi_v 而遗漏终点位置已经越界的情况。

第二，检查负加速度导致的区间内部最远点。只有在以下条件同时成立时，轨迹
才会在 0 到 d 之间出现速度为 0 的转向点：

    a < 0
    v > 0
    v_d <= 0

转向时刻为：

    t_turn = -v/a

该时刻的位置为：

    p_turn = p - v^2/(2*a)

要求 p_turn <= end，消去除法后等价于：

    v^2 <= -2*a*(end-p)

因此，phi_a 中的最后一个合取项：

    a >= 0
    or v <= 0
    or v_d > 0
    or v^2 <= -2*a*(end-p)

表示：如果区间内不存在上述转向点，只需依靠初始状态和周期终点的安全条件；
如果区间内存在转向点，则必须额外证明最远位置没有越过 end。

这个修改保留了原来的 phi_p 和 phi_v，只修复 phi_a 对连续区间中间状态检查
不足的问题。上述定义不依赖某一组具体物理参数；在每个给定的具体 d 下，
对于任意满足文件开头前提的 end、vmax、amin、amax，使用的都是同一个
参数化不变量模式。
